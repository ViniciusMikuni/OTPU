# Optimal transport for a global event description at high-intensity hadron colliders V2

# Perlmutter instructions

Almost all libraries required to run the training and plotting are already part of the tensorflow module (v2.15.0) with the need to only install:

```bash
module load tensorflow/2.15.0
pip install fastjet awkward mplhep
```

# Training

Let's copy the data to your own $SCRATCH area before running the training. Modify the target path to the one you want to use.

```bash
cp /global/cfs/cdirs/m3246/vmikuni/PU/*.h5 $SCRATCH/YOURFOLDER
```

Let's first test the training code by starting an interactive allocation and running for a few epochs

```bash
salloc -C gpu -q interactive  -t 40 -n 16 --ntasks-per-node=4 --gpus-per-task=1  -A m3246 --gpu-bind=none
#After your session starts do
module load tensorflow/2.15.0
srun python train.py --data_folder $SCRATCH/YOURFOLDER
```

If everything works out, you should be able to run the training using 16 GPUs! More GPUs or submission scripts for the training can be found in the ```submit.sh```. Additional options such as datasets to use are set in the config file ```config.json```.


# Clustering and plotting

After the training is done the next step is to evaluate the network results and save the jet information to new files that can be loaded quickly for plotting. This is accomplished by running the clustering script:

```
cd scripts
python cluster_results.py  --dataset test_DiJet.h5 --model SWDPU_NSWD4_delta 
```
You can evaluate over different samples and trained models based on the flags.Finally, plots are made using the files generated by the last step using:

```
cd scripts
python plot.py --dataset test_DiJet.h5 --model SWDPU_NSWD4_delta 
```
